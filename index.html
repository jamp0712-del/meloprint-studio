원본은 출력 배치이므로 조립 물림·실제 휨량은 확인되지 않았습니다. 물림 0.3~2mm는 선택값이며 처음에는 0.3mm부터 확인하세요. 빗 머리 아래 1.3mm 단차에는 서포트를 사용하세요.

제공한 원본 STL 그대로 받기 · kida 원본 생성기

카드는 실제 생성 형상의 빗살 한 개를 확대한 모습입니다. 네 방식에 같은 목표 음계·배치를 사용합니다. 키다·팅커비트 참고형은 원본 치수를 확인하지 못한 독립 비교용 형상이며 정확한 복제품이 아닙니다. 실제 음정은 각 방식의 출력물로 보정해야 합니다. 방식을 바꾸면 실측 확인이 해제됩니다.

방식별 위·아래 STL 2개씩, 총 8개와 라이노 생성 파일·SCAD·설정 포함. 한 방식의 두 판만 함께 조립하세요. 범위를 벗어나는 방식은 제외하고 안내문을 넣습니다. 33음은 MW4만 지원합니다.

사용 안내

  1. 멜로디 입력

    예제를 고르거나 도5, 레5 또는 C5 D5처럼 입력합니다. 기본 32칸, MW4는 33칸 이내이며 쉼표도 한 칸을 사용합니다.

  2. 생성 및 확인

    빗살 길이 15.68~29.68mm를 벗어나면 조옮김이나 PLA 보정값을 조절합니다. 치수를 임의로 잘라 음을 바꾸지 않습니다.

  3. 출력

    ZIP 안의 upper.stl과 lower.stl을 모두 출력합니다. 파일은 평평한 면이 바닥을 향합니다. PF2 11부품 + M3×5 나사 6개 구조(E, 베어링·너트 없음)를 사용하며 빗은 15·16번입니다.

  4. 라이노에서 편집

    받은 .py 파일을 Rhino 7의 빈 mm 문서에서 _RunPythonScript로 실행하면 두 개의 닫힌 서피스 솔리드를 생성합니다. 3DM으로 저장할 수 있습니다. Rhino 실제 실행은 아직 미검증입니다.

  5. 음정 보정

    현재 구조를 같은 재료·출력 방향으로 출력하고 조립한 뒤, 빗살의 직선 구간 길이와 실제 Hz를 입력해 다시 생성합니다. 한 음의 보정은 전체 음역의 정확도를 보장하지 않습니다.
