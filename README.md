| 버전 | 주소 | 내용 |
|---|---|---|
| **E2 (최신)** | https://jamp0712-del.github.io/meloprint-studio/ | 출력 부품 12개, 사서 쓰는 건 M3×5 나사 6개뿐(베어링·너트 없음), 25° 헬리컬 기어, 화살표 없이 빗살을 튕기는 피크가 상판 창으로 보임, 서포트 없이 모두 출력, 출력 판 3MF 4장 |
| E1 (이전) | https://jamp0712-del.github.io/meloprint-studio/e1/ | 출력 부품 12개, 평기어, 요크를 옆으로 눕혀 출력(서포트 필요) |
